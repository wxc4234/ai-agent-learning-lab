# 行为面试（BQ / HR）

社招必经的综合面与 HR 面。核心是把「我是前端转 AI 全栈」这条故事线讲自洽，动机、规划、薪资、离职原因都要有一致的话术。

## 主题分类

- `self-intro/` 自我介绍（30 秒 / 1 分钟 / 3 分钟版本）
- `motivation/` 转行动机（为什么从纯前端转 AI 全栈）
- `career/` 职业规划（3～5 年 / 为什么是我们公司）
- `strength-weakness/` 优缺点（用具体例子，不用套话）
- `conflict/` 冲突与协作（跨部门 / 意见分歧 / 压力）
- `failure/` 失败案例（讲反思与改进，不讲低级错误）
- `salary/` 薪资谈判（预期 / 依据 / 反套路）
- `questions/` 反问面试官（与 `LEARNING_CURRICULUM.md` 的反问清单联动）

## 答题模板（STAR + 取舍）

```markdown
# 问题

> 主题：xxx | 场景：技术面 / HR 面

## 考点（面试官想确认什么）

## 我的答案（STAR 版）

## 备选话术（不同公司/岗位的变体）

## 避坑（哪些说法会减分）
```
