# Workspace 目录规范化为何不能替代文件访问授权？

复习优先级：高。参考答案已整理、尚未模拟。

## 参考答案与取舍

项目入口要求本机绝对路径，并用 resolve(strict=True) 得到已存在的真实目标，再检查目录类型。保留合法空格，不展开 ~ 或环境变量，避免输入被隐式解释；拒绝文件系统根目录，限制过大的项目范围。入口允许符号链接，保存其规范目标。

用户选择目录入口与工具访问目录内文件是两层检查。入口解析成功不代表目录内软链接都可访问；文件工具必须根据实际目标检查是否落在绑定根目录内，不能只按字符串前缀判断。路径检查和打开文件之间可能发生替换，即 TOCTOU；真正的执行边界还需要操作时校验、适当的文件描述符策略与进程隔离，不能声称一次 resolve 已实现 Sandbox。

## 失败场景

目录不存在、普通文件、路径中间不是目录、失效/循环链接、权限不足与其他文件系统故障要区分。使用稳定业务错误码，响应不直接携带原始系统异常；验证成功只描述检查时刻，不保证之后仍存在或可写。

## 增量迁移如何兼容已有工作空间？

新增可空 Text 字段，NULL 明确表示未绑定，不设置默认项目或回填路径；旧应用省略此字段的创建仍可成功。模型与迁移同步维护 CHECK，但数据库仅拒绝空字符串，路径存在性仍属于服务层。迁移只能向前新增版本，不修改已执行的旧文件。历史迁移测试要对照历史结构快照，最新结构由新迁移测试验证。

## 并发绑定如何避免后来的请求覆盖项目目录？

按 Workspace 标识及归属 SELECT FOR UPDATE，锁内读取最新绑定值，再校验规范路径；首次绑定保存，同一规范路径重复成功，不同目录拒绝覆盖。所有绑定入口遵循该事务规则，不能用普通查询后无条件 UPDATE 替代。populate_existing 防止 Session 身份映射里的旧值掩盖数据库新值；no_autoflush 避免查询刷新其他待写数据。服务在 try 外拒绝已有事务，避免错误回滚调用方工作，成功前复制普通结果，commit 成功才返回。

项目证据：test_workspace_binding.py 的两类并发测试使用 pg_blocking_pids 确认实际锁等待，验证后来的请求读取首个已提交目录。16 条绑定专项加相关测试共 84 passed；提交故障在真实 flush 之后注入，独立连接验证回滚和恢复。此处验证提交前明确失败，不证明连接中断后的提交结果可判定。重复请求会重新验证目录，目录被删时不能承诺仍成功。目录校验期间持有行锁，因此不能在此事务内加入递归扫描或模型调用。

## 绑定接口返回 500 是否说明绑定没有发生？

不能。事务可能已提交，随后在构造响应时发生错误。HTTP 边界要使用“结果未确认”，前端不能自动按未提交处理或任意换绑；重复同一规范路径仍经过校验。服务异常与请求校验应转换为稳定错误码，不能反射原始路径、SQL 或异常正文。

证据：test_workspace_binding_api.py 在真实提交之后注入响应构造异常，验证安全 500、身份与业务 Session 关闭，以及独立连接读取的已保存路径。本课 HTTP 32 条，相关回归 78 passed。后端 HTTP 已完成，BFF/页面与文件授权仍待实现。参考答案已整理、尚未模拟。

## BFF 为什么必须匹配响应中的工作空间标识？

格式正确不代表响应属于当前操作。绑定 BFF 同时检查 external_id 与请求 ID 完全一致，仅复制 external_id/name/root_path，不透传内部字段或 Set-Cookie。内部凭证只由服务端注入，不采用浏览器伪造值。已知错误需同时匹配 HTTP 状态和自有错误码，用 Object.hasOwn 排除原型属性；使用本地文案，不反射异常正文。

证据：binding-route.test.ts 60 条通过，覆盖不同 ID、白名单、错误码错配、Unicode/路径，以及请求和响应正文阶段超时/取消且不自动重试。BFF 已完成，真实前后端集成及工作台入口尚待接入；取消代理并不回滚后端事务。参考答案已整理、尚未模拟。


## 为什么选择目录要经过本地服务，取消请求又不等于撤销保存？

浏览器目录控件提供相对路径或目录句柄，不能直接充当 Python Runtime 的本机绝对路径。当前本地 Web 产品通过严格本地 POST 请求打开系统目录窗口，选中后校验并保存；原生调用使用固定参数、不插入用户命令，先校验资源归属、释放数据库连接，再等待用户选择，保存时重新检查行锁与归属。窗口取消是正常 204；网络中断或返回失败则可能发生在提交之后，页面显示结果未确认并通过 GET 回读，不能自动重复选择或覆盖目录。

证据：test_directory_picker.py、test_workspace_selection_api.py 与 directory-select-route.test.ts 覆盖平台输出、超时/忙碌、取消无写入、本地访问边界、等待期间 Session 关闭、并发绑定冲突和白名单响应。原先 HTTP/BFF/页面待接入的限制已由目录选择交互补齐；文件授权与 Sandbox 仍未实现。复习优先级高，参考答案已整理、尚未模拟。
