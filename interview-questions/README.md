# 面试题库（AI 全栈工程师 · 社招）

面向「AI 全栈工程师」社招面试的系统化题库，覆盖算法、前端、后端、AI / LLM、系统设计、项目复盘、行为面试七个维度。

## 总体作战手册

开始刷题前，先看 [AI Agent 岗位面试作战手册：准备路线与 Codex 模拟面试](interview-action-plan-and-codex-mock.md)。它负责把目标岗位、ChatSearch 项目证据、学习计划、投递门槛、模拟面试提示词和评分复盘串成一套执行闭环；各子目录继续负责具体题目和答案。

## 与 LEARNING_CURRICULUM.md 的关系

本目录与 [`LEARNING_CURRICULUM.md`](../LEARNING_CURRICULUM.md) 第 4 章「面试题库」**互补，不重复**：

| 内容 | 位置 | 侧重点 |
| --- | --- | --- |
| Agent 应用层面试题（ReAct / MCP / 评测 / RAG pipeline 等，结合本项目） | `LEARNING_CURRICULUM.md` 第 4 章 | 按周积累，每题一行，无答案，偏**应用 + 项目佐证** |
| 通用全栈 + AI 原理层题库 | 本目录 `interview-questions/` | 每题一个文件，含考点、答案、追问，偏**原理 + 取舍** |

学习顺序建议：先做本目录的**原理层**题目打底，再回到 `LEARNING_CURRICULUM.md` 用项目把答案讲活。

## 准备优先级（精力怎么分配）

社招面试时间有限，别平均用力：

| 优先级 | 目录 | 精力占比 | 说明 |
| --- | --- | --- | --- |
| **P0 核心** | `ai/` `system-design/` `projects/` | 60% | AI 岗的区分项，面试重头戏 |
| **P1 保底** | `frontend/` `backend/` | 25% | 全栈底座，服务于 AI 场景，够用即可 |
| **P2 补强** | `algorithms/` `behavioral/` | 15% | 算法 Medium 为主；BQ 面试前突击 |

## 知识点 vs 项目：为什么不合并

面试常**从项目切入**来问技术，但知识点仍单独成库，原因见上文「社招答题心法」。两者的关联方式：

- 每个知识点题都带「**结合项目怎么讲**」栏，落到 `projects/` 里的具体项目。
- 每个 `projects/` 复盘反向链接它涉及的知识点题（跨目录 `../ai/xxx.md` 等）。
- 复习路径：**先走 `projects/` 的项目故事线，遇到讲不透的知识点，跳回对应目录补原理。**

## 社招答题心法（每个方向通用）

社招面试官要的不是「背定义」，而是三件事：

1. **能讲取舍**：为什么选 A 不选 B，代价是什么、怎么权衡。
2. **有项目佐证**：每个结论尽量落到「我在 xx 项目里是这样做的，遇到 xx 问题」。
3. **扛得住追问**：答案说完后，面试官一定会顺着往下问两到三层。

所以每题统一用下面的模板写，宁可少写「定义」，也要写「取舍 + 项目 + 追问」。

## 通用题解模板

```markdown
# 题目

> 标签：所属分类 | 频率：高 / 中 / 低 | 关联项目：xxx

## 考点（面试官在考察什么）
- 一句话说清这道题的区分度在哪。

## 核心答案（能直接讲出口的版本）
- 分点，讲取舍，不堆定义。

## 结合项目怎么讲
- 我项目里对应的实践 / 踩过的坑。

## 追问清单（高频追问，自问自答）

## 延伸 / 坑
```

## 维护规范

- 不按课程数量建题：只收录重要功能、关键取舍和工程难点。简单卡片展示、文案与样式修改无需单独入库；无新增重要考点时不新增题目。

- 学习课程验收后由教练主动归档重要题目及参考答案，不要求学习者当堂作答。按方向归类，已有同题优先更新，并同步分类 README 索引。
- 课程归档标记复习优先级（高/中/低，属于复习建议而非公开面试频率统计）、来源课程、项目证据和“参考答案已整理、尚未模拟”。不能虚构学习者原始回答或把参考答案写成已通过面试的记录。
- 用户要求模拟面试时，按目标岗位、优先级和已有薄弱点选题；课后归档本身不触发模拟面试。

- 每题一个文件，命名 `方向-主题-关键词.md`（小写英文 + 连字符），如 `ai-rag-pipeline.md`、`frontend-js-闭包.md`、`algorithms-001-two-sum.md`。
- 新增题目后，同步在该方向的 `README.md` 索引表登记一行。
- 标记「**[必问]**」代表公开题库统计里出现频率最高，优先准备。
- 每道题完成后把状态从 `待做` 改为 `已写`，便于追踪进度。
