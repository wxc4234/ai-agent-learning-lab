# 系统设计

社招面试的**重头戏**，也是 AI 全栈岗和普通后端岗最大的加分项。目标：每道题都能当场画出一张架构图，并讲清容量估算、数据流、扩展性与取舍。

## 内容分类

- `method/` 方法论（怎么讲系统设计：需求澄清 → 容量估算 → API 设计 → 数据模型 → 架构 → 扩展）
- `general/` 通用系统设计（短链 / Feed / IM / 限流 / 缓存 / 消息队列等经典题）
- `ai-system/` AI 系统设计（RAG 系统 / Agent 平台 / 可观测 / 多 Agent 编排 / 对话系统 / Computer Use 安全边界）

## 一张图的固定框架

```markdown
# 设计 XXX 系统

> 类型：通用 / AI | 频率：高/中/低

## 需求澄清（问面试官哪些问题）
## 容量估算（QPS / 存储 / 延迟）
## API 设计
## 数据模型
## 架构图（分层：接入 → 服务 → 数据 → 基础设施）
## 核心难点与取舍
## 扩展与演进
```
