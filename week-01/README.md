# 第 1 周：Python + FastAPI 最小闭环

日期：2026-08-24 ～ 2026-08-30  
建议投入：工作日 2 小时，周末 3～4 小时。

## 一周流程

```text
Python 语法
   ↓
环境与依赖
   ↓
FastAPI 接口
   ↓
LLM 调用
   ↓
整理项目 + 复盘
```

## 每日任务

| 日期 | 学习重点 | 当天必须产出 | 建议时间 |
|---|---|---|---|
| 周一 | Python 核心语法 | 完成变量、函数、列表、字典练习 | 2h |
| 周二 | 类、异常、文件与 JSON | 写一个读取 JSON 并处理异常的小程序 | 2h |
| 周三 | 虚拟环境、包管理、Git | 建立项目目录并完成首次代码提交 | 2h |
| 周四 | FastAPI 基础 | 完成 `GET /health` 与 `POST /chat` | 2h |
| 周五 | LLM API 调用 | 让 `/chat` 返回模型结果 | 2h |
| 周六 | 小项目整合 | 完成可运行的 AI 对话后端 | 3～4h |
| 周日 | 补漏与复盘 | 更新 README，记录问题和下周计划 | 2h |

## 学习规则

- 30% 看教程，70% 动手写。
- 卡住 20 分钟后再查资料或询问 AI。
- 每天至少提交一次 Git commit。
- 只学习本周项目会用到的知识。

## 本周验收清单

- [ ] 能解释 Python 函数、字典、异常处理。
- [ ] 能创建并启动 FastAPI 项目。

- [ ] GitHub 上有连续的学习提交记录。
