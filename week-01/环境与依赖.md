# 环境与依赖（week-01）

> 说明：`week-01/fastapi_app/` 里的代码用到几个第三方库，本文件说明**要装什么、怎么装、怎么用**。

## 1. 用到的第三方库

| 库 | 作用 | 在代码里的位置 |
|---|---|---|
| `fastapi` | Web 框架，写接口（`@app.post` / `@app.get` 等） | `chat_api.py`、`main.py` |
| `pydantic` | 数据校验，用 `BaseModel` 定义请求/响应结构 | `chat_api.py`、`main.py` |
| `python-dotenv` | 从 `.env` 文件读取环境变量 | `chat_api.py` |
| `openai` | 调用 DeepSeek 的 LLM API（OpenAI 兼容） | `chat_api.py` |
| `uvicorn` | ASGI 服务器，用来启动 FastAPI 应用 | 启动命令里 |
| `ruff` | 代码格式化/检查工具 | `.vscode/settings.json` |

> `sqlite3`、`os`、`json`、`pathlib` 都是 Python 标准库，**不用装**。

## 2. 安装

本项目用 **uv** 管理虚拟环境。`.venv` 里没有 pip，所以**不要用 `pip install`**（会报 `No module named pip`）。

```bash
# 1) 激活虚拟环境（Windows）
.venv\Scripts\activate

# 2) 安装全部依赖（在项目根目录执行）
uv pip install -r requirements.txt
```

只装某一个库：

```bash
uv pip install fastapi
```

## 3. 配置 API Key

`chat_api.py` 里是这样读 key 的：

```python
client = AsyncOpenAI(
    api_key=os.getenv("DEEPSEEK_API_KEY"),
    base_url="https://api.deepseek.com",
)
```

所以需要在项目根目录建一个 `.env` 文件：

```text
DEEPSEEK_API_KEY=sk-你的key
```

已提供 `.env.example` 模板：复制一份 → 重命名为 `.env` → 填入你的 key。
（`.env` 已被 `.gitignore` 忽略，不会提交到 GitHub。）

## 4. 运行

```bash
cd week-01/fastapi_app

# 运行 chat 接口（带 LLM）
uvicorn chat_api:app --reload
```

- 接口文档（Swagger）：http://127.0.0.1:8000/docs
- 用 curl 测 `/chat`：

```bash
curl -X POST http://127.0.0.1:8000/chat \
  -H "Content-Type: application/json" \
  -d "{\"session_id\":\"1\",\"prompt\":\"你好\"}"
```

`main.py` 是另一个练习接口（消息增删改查），单独跑：

```bash
uvicorn main:app --reload
```

## 5. 每个 import 分别对应什么

`chat_api.py` 顶部：

```python
import os                          # 标准库：读环境变量
from database import init_db        # 本地模块：初始化 SQLite 表

```

```python
import sqlite3            # 标准库：SQLite 数据库
from pathlib import Path  # 标准库：路径处理
```

## 6. 常见问题

- **`No module named pip`** → 用 `uv pip install`，不要用 `pip install`。
- **`ModuleNotFoundError: No module named 'fastapi'`** → 没激活 `.venv` 或没装依赖；先 `activate`，再 `uv pip install -r requirements.txt`。
- **VS Code 里 import 飘红** → 确认右下角解释器选的是 `.venv`（`settings.json` 里已配好 `python.defaultInterpreterPath`）。
